Privacy policy

Last updated 3 October 2026. This policy covers Geography Untangled Studio, the publishing tool used by the Geography Untangled YouTube channel.

Who uses it

Only the channel owner. The tool runs on the owner's own computer and signs in with the owner's own Google account. It does not collect information from viewers or any other person.

YouTube API Services

Geography Untangled Studio uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What it accesses

  • YouTube Data API: the owner's own videos, playlists, captions and thumbnails, to fill in video titles, descriptions, tags, captions, thumbnails, playlists and publish times.
  • YouTube Analytics API: the owner's own channel statistics, such as audience retention, to review how videos perform.

Where data is kept

The sign-in token and any statistics are stored only on the owner's computer. Nothing is sold, shared with third parties or used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions or through Google's security settings page at security.google.com/settings/security/permissions, and the stored token can be deleted from the owner's computer.

Contact

Through the Geography Untangled channel.
